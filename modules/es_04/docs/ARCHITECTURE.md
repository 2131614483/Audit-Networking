### 2.3 NLP声明抽取与结构化

#### 2.3.1 声明抽取

基于NLP的ESG声明自动抽取流水线：

```
ESG报告/年报 → 文本提取 → 声明检测 → 声明分类 → 论元抽取 → 结构化声明
```

| 声明类别 | 示例 | 抽取难度 |
|----------|------|----------|
| 排放声明 | "2025年碳排放较2020年下降30%" | 中 |
| 能源声明 | "可再生能源占比达到50%" | 中 |
| 水资源声明 | "单位产品用水量下降15%" | 中 |
| 废弃物声明 | "固废综合利用率达到95%" | 中 |
| 生物多样性声明 | "完成生态恢复面积200公顷" | 高 |
| 供应链声明 | "100%供应商通过绿色认证" | 高 |
| 认证声明 | "通过ISO 14001认证" | 低 |
| 承诺声明 | "承诺2030年实现碳中和" | 低 |

#### 2.3.2 声明可信度初步评估

- **量化程度**：是否包含具体数值、时间、范围（量化声明可信度更高）
- **模糊词检测**：检测"显著"、"大幅"、"领先"等模糊表述
- **可验证性**：声明是否具备可验证的客观条件
- **渠道一致性**：不同渠道的声明是否一致
- **历史对比**：与历史声明的对比分析

### 2.4 多源交叉验证引擎

#### 2.4.1 验证数据源

| 验证维度 | 数据源 | 验证内容 |
|----------|--------|----------|
| 卫星遥感 | Sentinel-2、PlanetScope、Landsat | 植被变化、水体污染、土地利用 |
| IoT传感器 | 环境监测站、企业排放监测 | 实时排放数据、能耗数据 |
| 政府监管 | 环保局处罚记录、环评批复 | 环境处罚、合规记录 |
| 第三方评级 | MSCI、CDP、Sustainalytics | ESG评分、争议事件 |
| 新闻舆情 | 新闻媒体、社交媒体 | 环境事件报道 |
| 行业数据 | 行业协会、研究机构 | 行业平均排放强度 |
| NGO报告 | 绿色和平、WWF等 | 环境调查报告 |

#### 2.4.2 验证方法

| 验证方法 | 适用场景 | 技术方案 |
|----------|----------|----------|
| 数值验证 | 量化声明验证 | 声明数值vs验证数据直接对比，计算偏差 |
| 趋势验证 | 变化趋势声明 | 验证数据时序趋势与企业声明趋势对比 |
| 逻辑验证 | 关系型声明 | 基于知识图谱推理，检查声明逻辑一致性 |
| 时空验证 | 空间相关声明 | 卫星影像时空分析与声明时空范围对比 |
| 对标验证 | 行业对比声明 | 与同行业企业数据进行对标分析 |
| 认证验证 | 认证相关声明 | 与认证机构数据库进行交叉查询 |

#### 2.4.3 偏差计算

```
偏差度 = |声明值 - 验证值| / 验证值 × 100%

声明可信度 = f(偏差度, 验证数据质量, 验证方法可靠性)
```

| 偏差范围 | 可信度等级 | 含义 |
|----------|-----------|------|
| <10% | 高可信 | 声明与验证数据基本一致 |
| 10-30% | 中等可信 | 声明存在一定偏差，需关注 |
| 30-50% | 低可信 | 声明与验证数据存在明显差距 |
| >50% | 不可信 | 声明极可能构成绿色漂洗 |

### 2.5 绿色漂洗检测模式

#### 2.5.1 检测模式库

| 检测模式 | 描述 | 检测规则 |
|----------|------|----------|
| 声明-事实差距 | 声明内容与实际数据不符 | 数值偏差超过阈值 |
| 选择性披露 | 只披露正面，隐瞒负面 | 正面声明有验证，负面事件未披露 |
| 模糊表述 | 使用无法验证的模糊语言 | 高频模糊词检测 |
| 虚假认证 | 声称未获得的认证 | 认证数据库交叉查询 |
| 时间错配 | 以旧数据冒充新进展 | 声明时间与数据时间不匹配 |
| 范围混淆 | 混淆不同核算范围 | Scope1/2/3声明与数据不匹配 |
| 基准操纵 | 选择有利基准年 | 基准年选择合理性分析 |
| 未来承诺替代当前行动 | 用未来承诺代替当前成效 | 承诺vs实际进展对比 |

#### 2.5.2 风险评分

```
绿色漂洗风险评分 = Σ(模式权重 × 模式匹配度) + 交叉验证偏差得分 + 企业历史得分
```

| 评分区间 | 风险等级 | 处置建议 |
|----------|----------|----------|
| ≥80分 | 高风险 | 启动专项调查，出具绿色漂洗警示报告 |
| 60-79分 | 中风险 | 安排深入验证，要求企业补充说明 |
| 40-59分 | 低风险 | 纳入观察清单，持续监控 |
| <40分 | 正常 | 常规监控，定期复核 |
