### 2.2 五级分类验证

#### 2.2.1 验证模型

| 模型 | 算法 | 输入特征 | 输出 |
|------|------|----------|------|
| 初始分类模型 | XGBoost多分类 | 客户信用评级、逾期天数、财务指标、行业风险 | 五级分类建议 |
| 迁移检测模型 | LightGBM二分类 | 当前分类vs模型预测的偏差 | 分类异常概率 |
| 时序验证模型 | LSTM | 历史还款记录、财务趋势 | 分类合理性评分 |

#### 2.2.2 验证流程

```
银行分类结果 → 模型预测 → 偏差检测 → 异常标注 → 审计建议
```

**偏差分析：**

| 偏差类型 | 说明 | 示例 |
|----------|------|------|
| 乐观偏差 | 银行分类优于模型预测 | 银行"正常"，模型"关注" |
| 悲观偏差 | 银行分类劣于模型预测 | 银行"次级"，模型"关注" |
| 时序偏差 | 分类调整滞后于风险变化 | 风险已上升，分类未调整 |
| 不一致偏差 | 同类客户分类不一致 | 相似风险客户分类不同 |

### 2.4 担保智能评估

#### 2.4.1 担保物价值评估

| 担保类型 | 评估方法 | 数据来源 |
|----------|----------|----------|
| 房产抵押 | 市场比较法+趋势调整 | 房产交易平台、评估报告 |
| 土地抵押 | 基准地价法+修正 | 自然资源部门数据 |
| 设备抵押 | 成本法+折旧 | 设备市场、评估报告 |
| 存货质押 | 市场法+变现折扣 | 大宗商品价格 |
| 股权质押 | 市值法+质押率 | 股票市场、评估报告 |
| 保证担保 | 保证人信用评估 | 征信、财务数据 |

#### 2.4.2 担保效力分析

基于知识图谱的担保关联分析：

- **担保链识别**：识别连环担保、互保、循环担保
- **担保集中度**：同一担保人担保金额集中度
- **担保效力评估**：担保合同有效性、抵质押登记状态
- **担保覆盖率**：担保价值/贷款余额比率
- **担保变现分析**：担保物变现能力和变现成本

### 2.5 风险预警

#### 2.5.1 预警指标体系

| 预警类别 | 指标 | 预警阈值 |
|----------|------|----------|
| 财务预警 | 利息保障倍数<1.5 | 黄色预警 |
| 经营预警 | 收入下降>30% | 橙色预警 |
| 担保预警 | 担保物价值下降>20% | 橙色预警 |
| 行为预警 | 贷款用途变更 | 红色预警 |
| 外部预警 | 行业风险上升 | 黄色预警 |
| 信用预警 | 征信记录恶化 | 红色预警 |

#### 2.5.2 预警模型

基于ML的早期预警模型：

```
输入 → 特征提取 → XGBoost/LightGBM → 违约概率预测 → 预警分级
```

- **预测窗口**：未来3/6/12个月违约概率
- **预警分级**：红/橙/黄三级预警
- **预警解释**：SHAP值解释主要预警因素
- **处置建议**：基于预警等级和原因的处置建议
