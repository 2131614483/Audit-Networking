### 2.2 ML人员技能画像模型

#### 2.2.1 技能评估维度

```
技能画像结构（每个审计师一个画像向量）：

1. 硬技能评分（10维，每维0-100）
   ├── 财务审计：基于CPA/ACCA认证+历史项目评分
   ├── IT审计：基于CISA/CISSP认证+IT审计项目数
   ├── 数据分析：基于SQL/Python/数据分析项目经验
   ├── 行业专长（按行业细分）：制造/金融/零售/科技/医药/能源
   ├── 语言能力：中文/英文/其他（按CEFR等级量化）
   ├── 风险评估：历史风险识别准确率
   ├── 内部控制：内控评估项目数+评分
   ├── 合规审计：合规项目经验
   ├── 舞弊调查：舞弊案例参与数
   └── ESG审计：ESG相关认证+项目经验

2. 软技能评分（5维，每维0-100，基于360度评估）
   ├── 沟通能力：客户反馈+团队评价
   ├── 领导能力：带队项目数+团队评分
   ├── 问题解决：历史问题解决效率评分
   ├── 时间管理：项目按时交付率
   └── 团队协作：同事互评得分

3. 经验指标（持续更新）
   ├── 总审计经验年限
   ├── 当前级别（初级/高级/经理/总监）
   ├── 已完成项目数（按类型分类）
   ├── 行业覆盖数
   └── 客户反馈平均分

4. 可用性（动态更新）
   ├── 当前项目占用工时
   ├── 未来N周可用工时
   ├── 已安排培训/休假时间
   ├── 当前所在城市
   └── 出差意愿（高/中/低）
```

#### 2.2.2 技能预测模型

```
ML模型：基于历史项目数据预测审计师在特定类型项目中的表现

输入特征：
  ├── 审计师画像向量（上述19维硬技能+软技能）
  ├── 项目类型特征（行业/复杂度/规模/技术需求）
  ├── 团队组合特征（团队成员历史合作次数/技能互补度）
  └── 时间特征（距上次同类项目天数）

输出：
  ├── 预期项目质量评分（0-100）
  ├── 预期效率评分（工时利用率预测）
  └── 预期客户满意度（0-100）

模型：XGBoost Regressor（多输出）
训练数据：过去3年500+项目的实际评分数据
验证指标：MAE < 8分

应用方式：
  - 在优化引擎中，使用预测评分替代静态技能评分
  - 对新入职审计师，使用相似画像预测初始技能评分
  - 每季度更新模型，纳入最新项目数据
```
