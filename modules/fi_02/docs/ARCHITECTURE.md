### 2.3 GNN风险分析

#### 2.3.1 模型架构

采用关系图卷积网络（R-GCN）进行担保风险建模：

```
输入：企业节点特征 + 担保关系特征
  ↓
R-GCN编码层（2层，隐藏维度256）
  ├── 关系感知消息传递
  ├── 邻域信息聚合（Sum/Mean/Attention）
  └── Dropout（0.2）
  ↓
风险预测层
  ├── 节点风险得分：Sigmoid分类
  ├── 风险传播路径：注意力权重
  └── 担保圈风险：图级池化
  ↓
输出：企业风险得分 + 风险传导路径 + 担保圈风险
```

#### 2.3.2 关键算法

| 算法 | 用途 | 技术方案 |
|------|------|----------|
| R-GCN | 节点风险评分 | 2层R-GCN，关系感知消息传递 |
| Louvain社区发现 | 互保圈识别 | 模块度优化 |
| PageRank变体 | 担保网络中心度 | 担保金额加权的PageRank |
| 子图匹配 | 特定担保模式 | VF2算法 |
| 图注意力 | 风险传导路径 | GAT注意力机制 |

### 2.4 互保圈识别

#### 2.4.1 担保圈模式

| 担保圈类型 | 结构特征 | 风险特征 |
|----------|----------|----------|
| 互保圈 | A↔B相互担保 | 捆绑风险，一方违约波及另一方 |
| 循环担保 | A→B→C→A循环担保 | 系统性风险，任一节点违约引发连锁反应 |
| 担保链 | A→B→C→D线性担保 | 风险沿链传导，末端风险最高 |
| 集中担保 | A→B,C,D,E | A集中担保多家，A的违约影响面大 |
| 担保网络 | 复杂网状结构 | 高度耦合，系统性风险高 |

#### 2.4.2 担保圈风险评分

```
担保圈风险评分 = 圈内企业平均风险 × 圈密度 × 圈规模 × 外部关联度
```

| 评分区间 | 风险等级 | 含义 |
|----------|----------|------|
| ≥80分 | 高风险圈 | 担保圈结构脆弱，风险传导可能 |
| 60-79分 | 中风险圈 | 担保圈有一定风险，需关注 |
| <60分 | 低风险圈 | 担保圈风险可控 |

### 2.5 压力测试

#### 2.5.1 测试场景

| 场景类型 | 场景描述 | 参数设定 |
|----------|----------|----------|
| 单一企业违约 | 某核心企业违约 | 违约损失率50-100% |

| 担保物贬值 | 担保物价值下降 | 价值下降30-50% |
| 流动性冲击 | 企业现金流紧张 | 现金流下降30% |

#### 2.5.2 风险传导模拟

基于独立级联模型的风险传导模拟：

```
初始违约节点 → 触发担保义务 → 担保方受影响 → 担保方违约 → 继续传导
                                    ↓
                             累计违约损失
```

**模拟输出：**

- **累计违约损失**：各场景下的总违约损失
- **受影响企业**：受传导影响的企业名单和受影响程度
- **关键风险节点**：对网络稳定性影响最大的节点
- **风险传导路径**：风险在企业间的传导路径
- **系统重要性排序**：各企业在担保网络中的系统重要性
