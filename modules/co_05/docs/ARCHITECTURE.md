│  图模式：多个源账户 → 多个中间账户 → 单个目标账户                   │
│  特征：                                                              │

│  图模式：账户A → 账户B → 账户C → ... → 账户A                       │
│  特征：                                                              │
│  ├── 资金在多个账户间流转后回到源头                                │
