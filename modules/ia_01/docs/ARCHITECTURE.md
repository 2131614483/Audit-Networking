#### 2.2.2 核心指标计算逻辑示例

```
┌─────────────────────────────────────────────────────────────────────┐
│  指标：收入波动异常指数 (Revenue Volatility Anomaly Index)          │
│                                                                     │
│  计算公式：                                                         │
│    RVA = |(实际收入 - 预测收入) / 预测收入| × 100                   │
│    预测收入 = 季节性ARIMA模型(过去36个月) + 外部市场增长率调整      │
│                                                                     │
│  风险信号阈值：                                                     │
│    - 正常：RVA < 15%                                                │
│    - 关注：15% ≤ RVA < 30%                                         │
│    - 预警：30% ≤ RVA < 50%                                         │
│    - 严重：RVA ≥ 50%                                               │
│                                                                     │
│  与风险评分的映射：                                                  │
│    风险贡献 = min(RVA × 0.5, 20) 分                                 │
│    即RVA每增加1%，风险评分增加0.5分，上限20分                        │
└─────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│  指标：负面新闻冲击指数 (Negative News Impact Index)                │
│                                                                     │
│  计算步骤：                                                         │
│    ① 通过NLP API采集目标企业及所在行业的中英文新闻                 │
│    ② 使用BERT模型进行情感分类（积极/中性/消极）                    │
│    ③ 对消极新闻进行实体识别（关联业务单元/产品/区域）              │
│    ④ 计算加权冲击指数：                                            │
│       NNI = Σ(每条新闻影响力权重 × 情感强度 × 关联度)              │
│       影响力权重 = 媒体权威性评分(0-1) × 阅读量归一化值             │
│       情感强度 = 消极情感得分(0-1)                                  │
│       关联度 = 实体匹配度(0-1)                                      │
│                                                                     │
│  风险贡献 = min(NNI × 10, 15) 分                                   │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.3 XGBoost风险评分模型

#### 2.3.1 模型架构

```
XGBoost风险评分模型设计

特征工程：
  ├── 数值特征（80维）：上述100+指标经PCA降维至80维
  ├── 类别特征（15维）：行业/业务类型/区域/流程类型等
  ├── 时间特征（5维）：距上次审计天数/距上次问题发现天数等
  └── 交叉特征（10维）：财务×运营组合/外部×内部组合等

模型配置：
  ├── 算法：XGBoost Regressor
  ├── 目标：0-100风险评分（连续值）
  ├── 训练数据：历史审计结果+已确认风险事件（5年数据）
  ├── 样本量：约50,000条（每个业务单元×每个评估周期）
  ├── 验证方式：5-fold交叉验证+时间序列回测
  ├── 超参数：
  │   ├── n_estimators: 500
  │   ├── max_depth: 8
  │   ├── learning_rate: 0.05
  │   ├── subsample: 0.8
  │   ├── colsample_bytree: 0.7
  │   └── eval_metric: rmse
  └── 特征重要性监控：每月分析Top 20特征，发现偏移自动告警

模型评估指标：
  ├── RMSE：目标<8（当前基线约15）
  ├── 风险排序准确率：目标>85%（高风险单元是否排在前20%）
  └── 预测风险vs实际风险相关性：目标Pearson r>0.7
```

#### 2.3.2 模型持续学习

```
在线学习流程：

每日批处理：
  ① 获取当天新发生的风险事件（审计发现/损失事件/管理层报告）
  ② 对比模型前一天的评分与该单元的实际风险状态
  ③ 计算预测误差，生成训练样本
  ④ 累积至周训练集

每周模型更新：
  ① 合并上周新样本（约500-1000条）
  ② 对近3个月样本加权（权重=1.5），历史样本降权（权重衰减因子0.98）
  ③ 增量训练XGBoost模型
  ④ A/B测试：新模型vs旧模型（对比1周预测准确率）
  ⑤ 如准确率提升>2%，自动部署新模型

季度全面重训：
  ① 使用全部历史数据重新训练
  ② 重新评估特征重要性，淘汰低效特征
  ③ 引入新数据源的新特征
  ④ 全面验证后部署
```
