### 2.2 实时数据流

#### 2.2.1 数据源接入

| 数据源类型 | 接入方式 | 数据量级 | 实时性要求 |
|------------|----------|----------|----------|
| 交易系统 | Kafka/CDC | 10万+ TPS | 秒级 |
| 财务系统 | Kafka/API | 1万+ TPS | 秒级 |
| 风控系统 | Kafka/CDC | 5万+ TPS | 秒级 |
| 日志数据 | Filebeat/Kafka | 100万+ TPS | 秒级 |
| IoT数据 | MQTT/Kafka | 10万+ TPS | 毫秒级 |
| 外部数据 | API/Kafka | 按需 | 分钟级 |

#### 2.2.2 流处理管道

```
数据源 → Kafka Topic → Flink作业 → 数据清洗 → 特征提取 → 规则/ML检查 → 结果输出
                           ↓                           ↓
                      Schema Registry             State Backend
```

- **Kafka**：高吞吐消息队列，支持数据持久化和回溯
- **Flink**：实时流处理引擎，Exactly-Once语义
- **Schema Registry**：数据Schema管理和兼容性检查
- **State Backend**：RocksDB状态后端，支持大状态管理
