### 2.2 实时数据采集

#### 2.2.1 数据源与采集策略

| 监控维度 | 数据源 | 采集频率 | 技术方案 |
|----------|--------|----------|----------|
| 舆情监控 | 新闻网站、财经媒体、行业论坛、社交媒体 | 实时（秒级） | 分布式爬虫+API订阅 |
| 司法监控 | 裁判文书网、执行信息网、破产公告 | T+1 | Web爬虫+RSS订阅 |
| 工商监控 | 企业信用信息公示系统 | T+1 | API定时同步 |
| 财务监控 | 企业财报、审计报告 | 季度（财报季增强） | 文件解析+API |
| 合规监控 | 环保处罚、市场监管处罚、行业监管 | 实时（小时级） | API+爬虫 |
| 信用监控 | 征信报告、评级机构 | 月度 | API定时同步 |

#### 2.2.2 实时数据处理流水线

```
数据源 → Kafka消息队列 → Flink流处理 → 数据清洗 → 特征提取 → 分析引擎
                           ↓                          ↓
                    数据湖（原始数据）          特征存储（Feature Store）
```

- **消息队列**：Apache Kafka，支持每秒百万级消息吞吐
- **流处理**：Apache Flink，毫秒级延迟，Exactly-Once语义
- **数据湖**：Apache Iceberg格式，支持时间旅行和增量查询
- **特征存储**：Feast开源特征存储，支持在线/离线特征统一管理

### 2.3 NLP风险事件分析

#### 2.3.1 事件抽取

基于预训练语言模型的事件抽取流水线：

```
输入文本 → 事件检测（是否为风险事件） → 事件类型分类 → 论元抽取 → 结构化事件
```

| 事件类型 | 触发词示例 | 关键论元 |
|----------|------------|----------|
| 破产/清算 | 破产、清算、重整、停业 | 企业名称、时间、原因 |
| 违约 | 违约、逾期、无法兑付 | 金额、涉及方、产品 |
| 诉讼/仲裁 | 起诉、诉讼、仲裁、判决 | 原告、被告、涉案金额 |
| 处罚/罚款 | 处罚、罚款、责令整改 | 处罚机关、金额、原因 |
| 环保事故 | 污染、超标、排放 | 污染物、超标倍数、罚款 |
| 负面舆情 | 曝光、质疑、投诉 | 媒体、内容摘要、传播量 |

#### 2.3.2 情感分析与影响力评估

- **情感分析**：基于FinBERT模型，输出正面/负面/中性判定及置信度
- **传播影响力**：综合媒体权重、转发量、评论量、阅读量计算影响力指数
- **事件热度**：基于时间衰减函数的实时热度计算，识别热搜事件
- **虚假信息检测**：基于多源交叉验证和来源可信度评估的信息真实性判断

### 2.4 ML风险预警模型

#### 2.4.1 预警模型体系

| 模型 | 用途 | 算法 | 输入特征 |
|------|------|------|----------|
| 风险事件识别 | 判断事件是否为真实风险 | XGBoost | 事件类型、来源可信度、情感得分、传播量 |
| 风险等级评估 | 评估风险严重程度 | LightGBM | 事件类型、涉及金额、影响范围、历史类似事件 |
| 影响范围预测 | 预测受影响供应商范围 | GNN传播模型 | 供应链图谱、事件类型、企业关联度 |
| 紧急度评估 | 评估处置紧迫性 | 规则+ML | 风险等级、影响范围、时间敏感度 |
| 处置建议生成 | 推荐最优处置方案 | 规则引擎 | 风险类型、等级、历史处置记录 |

#### 2.4.2 预警分级

| 级别 | 标识 | 定义 | 响应时间 | 处置要求 |
|------|------|------|----------|----------|
| 红色预警 | 🔴 紧急 | 可能导致供应商中断或重大损失 | 15分钟内 | 立即通知审计负责人+采购负责人，启动应急预案 |
| 橙色预警 | 🟠 重要 | 可能影响供应商正常履约 | 1小时内 | 通知相关审计人员，48小时内出具风险评估报告 |
| 黄色预警 | 🟡 关注 | 潜在风险，需持续跟踪 | 4小时内 | 纳入观察名单，每周更新风险状态 |
| 蓝色预警 | 🔵 提示 | 一般性信息通报 | 24小时内 | 记录归档，月度汇总 |

### 2.5 自动处置与工作流

#### 2.5.1 自动处置规则

| 预警级别 | 自动处置动作 |
|----------|-------------|
| 红色 | 自动创建紧急事件单→通知相关负责人→启动风险应对流程→生成风险简报 |
| 橙色 | 自动创建风险事件单→分配审计人员→推送风险详情→安排评估任务 |
| 黄色 | 自动添加至观察名单→生成风险摘要→更新供应商风险档案 |
| 蓝色 | 自动归档至信息库→月度汇总报告 |

#### 2.5.2 工作流引擎

基于Camunda BPMN工作流引擎，支持：

- 可视化流程设计
- 人工任务分配和转办
- 超时自动升级
- 流程追踪和审计日志
- 动态流程调整
