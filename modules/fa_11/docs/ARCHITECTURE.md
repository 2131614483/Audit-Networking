### 2.2 四种分析方法详细设计

#### 2.2.1 内部比较法

```
内部比较法 — 详细设计

适用条件：
  - 企业同时有同类关联交易和非关联交易
  - 交易数量足够进行统计检验（各≥10笔）
  - 交易条件可比（产品/服务/数量/地区/时间）

分析流程：
  ① 数据准备
     提取关联交易价格集合 P_related = {p1, p2, ..., pm}
     提取非关联交易价格集合 P_arm = {p1, p2, ..., pn}

  ② 描述性统计
     关联交易：均值/中位数/标准差/Q1/Q3
     非关联交易：均值/中位数/标准差/Q1/Q3
     差异：绝对差异 + 相对差异（%）

  ③ 统计检验
     正态性检验（Shapiro-Wilk）：
       IF p值>0.05 → 数据正态，使用t检验
       IF p值≤0.05 → 数据非正态，使用Mann-Whitney U检验

     t检验（正态）：
       H0: 关联交易定价 = 非关联交易定价
       H1: 关联交易定价 ≠ 非关联交易定价
       IF p值<0.05 → 拒绝H0，定价存在显著差异

     Mann-Whitney U检验（非正态）：
       H0: 两组数据分布相同
       IF p值<0.05 → 拒绝H0，定价存在显著差异

  ④ 判定标准
     ┌─────────────────────────────────────────────────────────┐
     │ 条件                  │ 结论               │ 风险等级  │
     ├───────────────────────┼────────────────────┼──────────┤
     │ p≥0.05 且 差异<5%     │ 定价公允            │ 🟢 低    │
     │ p≥0.05 但 差异5-10%   │ 基本公允，需关注     │ 🟡 中    │
     │ p<0.05 或 差异>10%    │ 定价可能不公允      │ 🔴 高    │
     │ p<0.01 或 差异>20%    │ 定价不公允          │ 🔴 严重  │
     └─────────────────────────────────────────────────────────┘

示例输出：
  ┌─────────────────────────────────────────────────────────────┐
  │ 内部比较法分析结果                                          │
  │ 交易类型：原材料采购-钢材                                   │
  │ 关联方：XX钢铁有限公司（子公司）                             │
  │                                                             │
  │ 关联交易均价：¥3,850/吨（20笔）                            │
  │ 非关联交易均价：¥3,620/吨（35笔）                          │
  │ 差异：+¥230/吨（+6.35%）                                   │
  │                                                             │
  │ 统计检验：Mann-Whitney U = 180, p = 0.023 < 0.05           │
  │ 结论：定价存在统计显著差异，关联交易定价偏高6.35%          │
  │ 风险评估：🔴 高                                            │
  └─────────────────────────────────────────────────────────────┘
```
