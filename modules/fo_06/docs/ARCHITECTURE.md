### 2.2 模块详细设计

#### 2.2.1 证据图谱构建引擎

证据图谱是证据链构建的基础，将分散的证据组织为结构化的关联网络。

**实体类型**：

| 实体 | 属性 | 来源 |
|------|------|------|
| 证据文档 | ID、名称、类型、来源、时间戳、哈希值 | 各类证据源 |
| 人员 | 姓名、角色、部门、关联案件 | 证据中提取 |
| 事件 | 时间、地点、类型、描述 | 证据中提取 |
| 交易 | 金额、方向、时间、账户 | 交易数据 |
| 资产 | 类型、金额、所有人、所在地 | 证据中提取 |
| 账户 | 账号、银行、持有人 | 交易/文档数据 |

**关系类型**：

| 关系 | 说明 | 发现方式 |
|------|------|---------|
| 包含 | 证据文档包含某实体/事件 | NER抽取 |
| 参与 | 人员参与某事件 | 关系抽取 |
| 关联 | 实体之间的关联关系 | 图谱分析 |
| 指向 | 证据指向某结论 | 推理引擎 |
| 时序 | 事件之间的先后关系 | 时间线引擎 |
| 因果 | 事件之间的因果关系 | 推理引擎 |

#### 2.2.2 时间线生成引擎

**时间提取**：
- 从证据文本中提取时间表达式（"2024年1月15日"、"去年Q3"等）
- 时间归一化（统一为ISO 8601格式）
- 时间模糊度标注（精确/日/月/年级别）

**事件排序**：
- 基于时间的线性排序
- 多证据交叉验证时间准确性
- 时间冲突检测与标记

**时间线可视化**：
- 交互式时间轴
- 事件分组（按阶段/类型/重要性）
- 多轨道展示（不同人员/不同证据源）

#### 2.2.3 证据推理引擎

基于LLM的证据推理引擎是证据链构建的智能核心。

**推理能力**：

| 推理类型 | 说明 | 技术 |
|---------|------|------|
| 因果推理 | 从证据中发现因果关系 | LLM+因果图 |
| 时序推理 | 基于时间顺序的逻辑推理 | LLM+时间约束 |
| 假设验证 | 验证调查假设是否被证据支持 | LLM+证据检索 |
| 反事实推理 | 假设性推理（如果...会...） | LLM推理 |
| 归纳推理 | 从具体证据中归纳一般结论 | LLM+多证据综合 |

**推理流程**：
1. 用户提出调查问题或假设
2. 从证据图谱中检索相关证据子图
3. LLM基于证据子图进行推理
4. 生成推理路径和结论
5. 标注推理置信度

#### 2.2.4 证据完整性检查

**完整性维度**：

| 维度 | 检查内容 | 检测方法 |
|------|---------|---------|
| 时间完整性 | 时间线是否存在时间缺口 | 时间间隔分析 |
| 实体完整性 | 关键实体是否都有对应的证据 | 实体-证据映射 |
| 因果完整性 | 因果关系链是否完整 | 因果图分析 |
| 逻辑完整性 | 证据链逻辑是否自洽 | 逻辑矛盾检测 |
| 来源完整性 | 是否有多源交叉验证 | 证据来源分析 |

**完整性评分**：
```
完整性评分 = (已有证据数 / 应有证据数) × 权重1 
           + (多源验证比例) × 权重2 
           + (时间覆盖度) × 权重3
```

#### 2.2.5 证据关联发现

**关联发现方法**：

| 方法 | 技术 | 发现类型 |
|------|------|---------|
| 实体共现 | 同一实体出现在不同证据中 | 直接关联 |
| 路径发现 | 图谱中的间接路径 | 间接关联 |
| 相似性匹配 | 证据内容的语义相似度 | 内容关联 |
| 时序关联 | 时间相近的事件 | 时序关联 |
| 模式匹配 | 匹配已知证据模式 | 模式关联 |
