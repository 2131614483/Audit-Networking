### 2.2 敏感数据识别模型

#### 2.2.1 识别模型架构

```
敏感数据识别流水线：

阶段1：数据采样
  对大规模数据集进行智能采样：
  ├── 结构化数据：按表分区采样（每表至少10,000行或10%）
  ├── 半结构化数据：按文档类型采样（JSON/XML/CSV）
  └── 非结构化数据：按文件大小采样（文本抽取前N页）

阶段2：模式匹配（规则引擎）
  并行执行100+正则表达式模式：
  ├── 身份证号：\d{17}[\dXx] 或 \d{15}（中国）
  ├── 信用卡号：(?:\d[ -]*?){13,16}（Luhn校验）
  ├── 邮箱：[\w\.-]+@[\w\.-]+\.\w+
  └── 电话号码：\+?\d{1,3}[-.\s]?\d{3,4}[-.\s]?\d{4}
  
  匹配结果：
  ├── 匹配数量/总行数 → 敏感数据密度
  ├── 匹配类型分布 → 敏感数据类型
  └── 置信度：模式匹配（高/中/低）

阶段3：NLP语义识别（BERT模型）
  对采样数据进行语义分析：
  ├── 输入：字段名+字段值样本+表注释+列注释
  ├── 编码：BERT tokenizer（多语言支持）
  ├── 模型：BERT-base（微调数据分类）
  ├── 输出：敏感数据类型概率分布
  └── 标签：PII/财务/医疗/HR/商业/其他

阶段4：综合判定
  融合规则引擎+NLP结果：
  ├── 规则引擎高置信度（>95%）：直接采用规则结果
  ├── 规则引擎中低置信度（<95%）：NLP模型补充判定
  ├── 规则引擎未匹配：完全依赖NLP模型
  └── 综合置信度：规则权重×0.6 + NLP权重×0.4
```

### 2.3 数据资产分类体系

#### 2.3.1 五级分类标准

```
数据资产分类体系（五级+三维）：

敏感等级（纵向）：
  ├── L0 公开（Public）
  │   定义：可对外公开的信息
  │   示例：企业官网信息/公开年报/产品介绍
  │   保护要求：无特殊保护
  │   合规要求：无
  │
  ├── L1 内部（Internal）
  │   定义：企业内部使用，不对外公开
  │   示例：内部通讯录/组织架构/内部制度
  │   保护要求：基本访问控制
  │   合规要求：无特殊
  │
  ├── L2 敏感（Sensitive）
  │   定义：泄露可能对企业或员工造成中等损害
  │   示例：员工薪酬/绩效考核/客户联系方式
  │   保护要求：加密存储+权限控制+访问审计
  │   合规要求：GDPR Art.32/PIPL
  │
  ├── L3 机密（Confidential）
  │   定义：泄露可能对企业造成严重损害
  │   示例：财务数据/商业合同/客户名单/定价策略
  │   保护要求：强加密+最小权限+严格审计+DLP
  │   合规要求：SOX/PCI-DSS
  │
  └── L4 受限（Restricted）
      定义：受法律法规严格保护，泄露后果极其严重
      示例：个人身份信息(PII)/医疗记录/生物特征/基因数据
      保护要求：最高级别加密+脱敏+访问审批+全链路审计
      合规要求：GDPR/CCPA/PIPL/HIPAA/GLBA

数据类别（横向）：
  ├── 个人数据：姓名/身份证/电话/地址/生物特征

  ├── 业务数据：客户/合同/订单/供应链/定价

  ├── HR数据：薪酬/绩效/背景/健康/考勤
