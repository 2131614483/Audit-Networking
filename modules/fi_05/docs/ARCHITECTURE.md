### 2.2 监管文件采集

| 监管机构 | 文件类型 | 采集频率 |

| 国家金融监督管理总局 | 监管规定、通知、指引 | 实时 |
| 中国证监会 | 管理办法、信息披露规则 | 实时 |

| 中国银行业协会 | 行业自律规则 | 日度 |

#### 2.2.2 采集方式

- **官网监控**：监管机构官网RSS订阅+定时爬虫
- **文件订阅**：官方文件发布订阅服务
- **行业渠道**：行业协会通知转发
- **智能去重**：相同内容的多渠道发布自动去重

### 2.3 NLP口径变化识别

#### 2.3.1 文本分析流水线

```
监管文件 → 文本提取 → 段落分割 → 语义理解 → 变化检测 → 变化描述
```

| 分析任务 | 技术方案 | 用途 |
|----------|----------|------|
| 文件分类 | BERT文本分类 | 按机构、类型、主题分类 |
| 关键信息抽取 | BERT-BiLSTM-CRF | 提取文件编号、生效日期、适用范围 |
| 语义比对 | SBERT语义相似度 | 新旧文件语义对比 |
| 变化检测 | LLM+规则 | 识别口径变化内容 |
| 影响范围分析 | LLM推理 | 分析变化影响的报表和指标 |

#### 2.3.2 变化类型识别

| 变化类型 | 描述 | 示例 |
|----------|------|------|
| 口径定义变化 | 指标计算口径调整 | "普惠型小微企业贷款"定义调整 |
| 报送要求变化 | 报表格式或频率变化 | 新增报表GXX，取消报表GYY |
| 阈值标准变化 | 监管指标阈值调整 | 资本充足率要求从10.5%调整为11% |
| 披露要求变化 | 信息披露内容变化 | 新增ESG相关披露要求 |
| 适用范围变化 | 适用机构范围调整 | 扩大至城商行 |

#### 2.4.2 影响分析

| 影响维度 | 分析内容 | 分析方式 |
|----------|----------|----------|
| 报表影响 | 影响的报表和具体数据项 | 知识图谱匹配 |
| 指标影响 | 影响的监管指标和计算方式 | 规则引擎+LLM |
| 系统影响 | 影响的IT系统和功能模块 | 系统依赖分析 |
| 流程影响 | 影响的业务流程和操作 | 流程关联分析 |
| 人员影响 | 影响的相关岗位和人员 | 组织架构匹配 |

### 2.5 变更管理

#### 2.5.1 变更流程

```
监管文件发布 → 自动采集 → 变化识别 → 影响分析 → 更新建议生成
                                                      ↓
                                               人工审核确认
                                                      ↓
                                               更新任务分配
                                                      ↓
                                               更新执行跟踪
                                                      ↓
                                               更新验证确认
                                                      ↓
                                               变更历史记录
```

#### 2.5.2 变更追踪

- **变更日历**：所有监管口径变更的时间线
- **变更状态**：待处理/处理中/已完成/已验证
- **变更影响矩阵**：变更与报表/指标/系统的关联矩阵
- **合规检查**：口径更新是否满足监管要求的时间节点
