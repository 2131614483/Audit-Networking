### 2.2 RPA自动采集

#### 2.2.1 采集场景

| 系统类型 | 采集方式 | 采集内容 | 频率 |
|----------|----------|----------|------|
| 核心银行系统 | 数据库直连+API | 资产负债数据 | 日度 |
| 信贷管理系统 | 数据库直连 | 贷款明细、五级分类 | 日度 |
| 财务系统 | API+RPA | 损益数据、财务指标 | 日度 |
| 风险管理系统 | 数据库直连 | 风险加权资产、资本充足率 | 日度 |
| 监管报送系统 | RPA+文件 | 已报送报表 | 按需 |

#### 2.2.2 RPA流程

```
定时触发 → 登录系统 → 数据提取 → 数据校验 → 异常处理 → 数据入库
```

- **异常处理**：登录失败、数据异常、系统超时等自动处理
- **监控告警**：RPA运行状态监控，失败自动告警
- **日志记录**：完整的操作日志，支持审计追溯

### 2.3 规则引擎

#### 2.3.1 勾稽关系规则库

| 规则类型 | 规则示例 | 规则数量 |
|----------|----------|----------|
| 表内勾稽 | 资产总额=负债总额+所有者权益 | 500+ |
| 表间勾稽 | 利润表净利润=资产负债表中未分配利润变动 | 300+ |
| 跨期勾稽 | 本期期初余额=上期期末余额 | 200+ |
| 报送口径 | 不同报表同一指标口径一致性 | 200+ |
| 监管指标 | 资本充足率≥10.5% | 100+ |
| 逻辑校验 | 贷款余额≤贷款限额 | 150+ |

#### 2.3.2 规则执行

```
报表数据 → 规则加载 → 规则匹配 → 规则执行 → 结果输出
                                    ↓
                             差异记录
```

- **规则引擎**：基于Drools/EasyRules的轻量级规则引擎
- **规则管理**：可视化规则编辑、版本管理、测试沙箱
- **执行计划**：按报表报送周期自动触发核对
- **结果分级**：错误/警告/提示三级结果分级

### 2.4 ML异常检测

#### 2.4.1 检测模型

| 模型 | 用途 | 算法 |
|------|------|------|
| 数据异常检测 | 识别异常数据波动 | 孤立森林 |
| 趋势异常检测 | 识别趋势突变 | Prophet+异常检测 |
| 模式异常检测 | 识别异常数据模式 | 自编码器 |
| 跨表一致性 | 检测跨表数据不一致 | XGBoost二分类 |

#### 2.4.2 异常分析

- **异常评分**：综合ML模型和规则引擎结果
- **异常分类**：数据错误/口径差异/逻辑错误/系统问题
- **根因分析**：基于数据血缘的差异溯源
- **影响评估**：差异对监管指标的影响程度

### 2.5 差异追踪

#### 2.5.1 差异管理流程

```
差异检测 → 差异记录 → 根因分析 → 责任分配 → 整改跟踪 → 关闭确认
```
