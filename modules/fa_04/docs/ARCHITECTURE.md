### 2.2 区块链函证工作流

```
区块链函证工作流（详细）

┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ 审计师    │     │ 智能合约  │     │ 银行节点  │     │ 区块链   │
│ 发起函证  │ ──→ │ 验证身份  │ ──→ │ 接收函证  │ ──→ │ 存证函证 │
│          │     │ 格式化    │     │          │     │ (不可篡改)│
└──────────┘     └──────────┘     └──────────┘     └──────────┘
     │                │                │                │
     ▼                ▼                ▼                ▼
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ 银行系统  │     │ 回函数据  │     │ 审计师    │     │ 审计底稿  │
│ 自动查询  │ ──→ │ 数字签名  │ ──→ │ 接收回函  │ ──→ │ 自动归档  │
│ 账户数据  │     │ +时间戳   │     │ +自动比对  │     │ +差异处理 │
└──────────┘     └──────────┘     └──────────┘     └──────────┘

智能合约逻辑：
  IF 审计师身份验证通过 AND 函证格式校验通过
  THEN 自动转发至银行节点
  AND 记录函证哈希值至区块链
  AND 启动回函计时器（48小时超时）

  IF 银行节点验证通过 AND 账户数据查询完成
  THEN 自动生成回函（数字签名+时间戳）
  AND 回函哈希值写入区块链
  AND 自动发送回函至审计师

  IF 审计师收到回函 AND 自动比对完成
  THEN 比对结果哈希值写入区块链
  AND 差异处理记录写入区块链
  AND 函证闭环完成
```

### 2.4 AI差异智能分析

```
AI差异分析流程

差异类型分类：
  ┌─────────────────────────────────────────────────────────┐
  │ ① 金额差异（最常见）                                    │
  │    审计方金额 vs 银行方金额不一致                        │
  │    AI分析：                                              │
  │    • 时间差异：审计截止日 vs 银行记账日差异              │
  │    • 未达账项：在途存款/未兑现支票/在途付款             │
  │    • 利息/手续费：银行自动扣收利息/手续费未入账         │
  │    • 汇率差异：外币账户的汇率折算差异                   │
  │    自动生成：未达账项调节表                              │
  │                                                         │
  │ ② 账户信息差异                                          │
  │    账号/户名/币种不一致                                  │
  │    AI分析：                                              │
  │    • 账号错误：审计方录入错误                            │
  │    • 户名变更：企业更名但未通知                          │
  │    • 币种错误：原币vs本位币混淆                          │
  │                                                         │
  │ ③ 利率/期限差异                                         │
  │    存款利率/贷款利率/定期存款期限不一致                   │
  │    AI分析：                                              │
  │    • 利率调整：浮动利率随市场变化                        │
  │    • 自动转存：到期自动转存导致期限变化                  │
  │                                                         │
  │ ④ 冻结/担保差异                                         │
  │    账户冻结状态/担保信息不一致                            │
  │    AI分析：                                              │
  │    • 司法冻结：审计方未知悉的司法冻结                    │
  │    • 质押担保：审计方未记录的质押信息                    │
  └─────────────────────────────────────────────────────────┘

差异处理建议（LLM生成）：
  例：金额差异¥12,345.67
  AI分析结果：预计为"未达账项-在途存款"
  → 建议：补充2025-12-31至2025-01-05期间的银行流水
  → 确认在途存款实际到账日期
  → 生成未达账项调节表
```
