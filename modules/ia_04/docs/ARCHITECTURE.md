```
┌──────────────────────────────────────────────────────────────────────┐

│  │   ├── 风险降低价值（风险敞口减少金额）                            │
│  │   ├── 合规价值（避免的监管处罚+合规改善）                        │

│  ├── 审计ROI（投入产出比）                                           │
│  ├── 风险覆盖率（高风险区域审计覆盖比例）                            │
│  ├── 整改完成率（按期完成整改/总整改项）                            │
