### 2.3 差异识别与分析

#### 2.3.1 自动差异识别

```
源准则财务报表 → 准则识别 → 差异检测 → 影响评估 → 调整建议
```

| 差异类型 | 识别方法 | 输出 |
|----------|----------|------|
| 会计政策差异 | LLM+规则匹配 | 政策差异清单 |
| 计量方法差异 | 公式+规则比对 | 计量差异计算 |
| 分类列报差异 | 分类映射匹配 | 重分类调整 |
| 披露要求差异 | 披露清单比对 | 补充披露清单 |

#### 2.3.2 差异影响评估

- **定量影响**：差异对主要财务指标的影响金额
- **定性影响**：差异对财务报告使用者的理解影响
- **重要性评估**：基于金额和性质的重要性判断
- **累积影响**：多项差异的累积影响
