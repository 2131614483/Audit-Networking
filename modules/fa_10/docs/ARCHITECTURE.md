### 2.2 隐藏关联发现算法

```
GNN隐藏关联发现算法

输入：知识图谱 G(V, E, X)
  V: 实体节点（公司/个人/账户/地址/电话/邮箱）
  E: 关系边（股权/任职/交易/担保/地址/电话/邮箱）
  X: 节点特征（注册资本/持股比例/交易金额/风险评分）

算法：GraphSAGE + GAT（图注意力网络）

步骤1：节点嵌入
  • 对公司节点：聚合其股东信息、对外投资信息、交易对手信息
  • 对个人节点：聚合其任职公司、持股公司、关联地址/电话
  • 输出：每个节点的128维嵌入向量

步骤2：关系预测（Link Prediction）
  • 预测两个实体之间是否存在"隐藏关联"
  • 特征：节点嵌入相似度 + 路径长度 + 中间节点类型
  • 模型：MLP(256->128->1) + Sigmoid
  • 训练数据：已知关联关系作为正样本，随机对作为负样本
  • 评估指标：AUC > 0.95

步骤3：子图异常检测
  • 检测异常的子图结构模式
  • 模式库：环形持股、星型代持、链式控制、多层嵌套
  • 使用Weisfeiler-Lehman图核进行子图匹配

步骤4：风险评分
  • 综合得分 = α×关联强度 + β×隐藏深度 + γ×异常模式 + δ×交易金额
  • 权重(α,β,γ,δ)通过历史数据训练
  • 输出：每个候选关联方的风险评分(0-100)

发现能力对比：
  ┌─────────────────────────────────────────────────────────┐
  │ 关联跳数    手工能力    AI能力    AI增量                │
  │ 1跳（直接）   90%      100%      +10%                  │
  │ 2跳（间接）   30%      95%       +65%                  │
  │ 3跳          5%        80%       +75%                  │
  │ 4跳          1%        60%       +59%                  │
  │ 5+跳         <0.1%     40%       +39.9%               │
  └─────────────────────────────────────────────────────────┘
```

### 2.3 关联交易定价公允性分析

```
关联交易定价公允性ML分析

数据源：
  • 关联交易明细（交易金额/数量/日期/产品/服务类型）
  • 非关联交易明细（可比交易，同一企业或行业）
  • 同行业可比交易数据（行业数据库）
  • 市场基准价格（公开市场价格/第三方估值）

分析方法：

① 内部比较法（同一企业）
  比较同一企业关联交易 vs 非关联交易的价格差异
  统计检验：t检验/Mann-Whitney U检验
  判定：p值<0.05且差异>5% → 定价可能不公允

② 外部比较法（同行业）
  比较关联交易定价 vs 行业平均定价
  使用行业数据库（同产品/同地区/同规模）
  判定：超出行业平均±2σ → 定价可能不公允

③ 转移定价调整法
  适用：关联交易涉及跨境/税收优惠地区
  使用TNMM（交易净利润法）或PSM（利润分割法）
  判定：利润率超出四分位区间 → 需调整

④ 时间序列异常检测
  比较同一关联交易的历史定价变化
  识别：定价突然偏离历史趋势的交易
  判定：同比变化>30%且无合理解释 → 需关注

报告输出：
  ┌─────────────────────────────────────────────────────────┐
  │ 关联交易定价公允性分析报告                              │
  │                                                         │
  │ 高风险关联交易（3项）：                                  │
  │ 1. 向关联方A销售商品 ¥500万，单价¥100/件               │
  │    非关联方同类产品均价¥80/件，差异+25%                 │
  │    → 定价偏高，可能为利益输送                          │
  │                                                         │
  │ 2. 向关联方B采购服务 ¥300万                            │
  │    无市场可比价格，服务内容描述模糊                     │
  │    → 定价依据不充分，需补充服务内容说明和定价依据       │
  │                                                         │
  │ 3. 向关联方C借款 ¥1000万，利率3.5%                     │
  │    同期银行贷款利率4.5%，差异-1%                        │
  │    → 利率偏低，需确认是否为无偿资助                    │
  └─────────────────────────────────────────────────────────┘
