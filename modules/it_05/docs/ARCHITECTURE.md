### 2.2 模块详细设计

#### 2.2.1 日志摘要引擎

日志摘要引擎负责将审计日志生成固定长度的哈希摘要，作为上链存证的数据基础。

**哈希算法**：
- 主算法：SHA-256
- 国密支持：SM3（中国国家密码标准）
- 批量处理：Merkle Tree（批量日志摘要聚合）

**摘要策略**：

| 策略类型 | 说明 | 适用场景 |
|---------|------|---------|
| 单条摘要 | 每条日志单独生成哈希值 | 高价值审计日志（如权限变更） |
| 批次摘要 | 批量日志生成Merkle Root | 大量常规日志（如访问日志） |
| 时间窗口摘要 | 固定时间窗口内的日志聚合摘要 | 持续审计场景 |
| 混合摘要 | 单条+批次组合策略 | 灵活配置 |

**Merkle Tree设计**：
```
        Root Hash
       /         \
     H12         H34
    /    \      /    \
  H1     H2   H3     H4
  │      │    │      │
Log1   Log2  Log3  Log4
```

#### 2.2.2 存证上链服务

存证上链服务负责将日志摘要写入区块链。

**上链流程**：
1. 接收日志摘要请求
2. 使用私钥对摘要进行数字签名
3. 构建区块链交易（Transaction）
4. 广播交易到区块链网络
5. 等待交易确认（区块打包）
6. 返回交易ID和区块信息

**交易数据结构**：
```json
{
  "version": "1.0",
  "timestamp": 1719504000000,
  "signature": "MEUCIQD...",
  "signer": "audit-node-01",
  "data": {
    "digest_type": "SHA-256",
    "digest_value": "a1b2c3d4e5f6...",
    "source_system": "ERP-SAP-PRD",
    "log_type": "USER_PERMISSION_CHANGE",
    "log_time_range": ["2024-06-01T00:00:00Z", "2024-06-01T23:59:59Z"],
    "log_count": 1523,
    "metadata": {
      "audit_id": "AUD-2024-0612",
      "department": "Finance"
    }
  }
}
```

#### 2.2.3 完整性验证引擎

完整性验证引擎提供审计证据的在线和离线验证能力。

**验证流程**：
1. 从链下存储获取原始日志
2. 使用相同算法计算日志摘要
3. 从区块链查询存证的摘要值
4. 比对链上链下摘要是否一致
5. 验证数字签名是否有效
6. 输出验证结果（通过/失败）

**验证方式**：
- **在线验证**：通过API实时验证
- **批量验证**：批量日志文件的完整性验证
- **离线验证**：导出Merkle Proof进行离线验证
- **定期验证**：定时自动全量验证

#### 2.2.4 数字签名服务

**签名算法**：
- ECDSA（P-256/P-384）
- 国密SM2
- Ed25519

**密钥管理**：
- 硬件安全模块（HSM）存储私钥
- 密钥轮换策略（每90天）
- 多签机制（重要存证需要多方签名）

#### 2.2.5 证据链构建引擎

**功能**：
- 按审计项目关联多笔存证记录
- 构建审计证据的时间线
- 生成证据关联图谱
- 支持证据链的完整性和一致性检查

### 2.3 区块链网络设计

#### 2.3.1 网络拓扑

采用联盟链架构，由多方共同维护：

| 节点 | 部署方 | 角色 | 数量 |
|------|--------|------|------|
| 审计节点 | 审计部门 | 共识+存证提交 | 2 |
| IT节点 | IT部门 | 共识+数据提供 | 2 |
| 合规节点 | 合规部门 | 共识+验证 | 1 |
| 监管节点 | 外部监管机构 | 共识+监管审计 | 1 |
| 公证节点 | 第三方公证 | 共识+见证 | 1 |

#### 2.3.2 共识机制

- **主共识**：Raft（CFT）/ PBFT（BFT）
- **容错能力**：支持1/3节点故障（PBFT）
- **交易吞吐量**：>1000 TPS
- **确认时间**：<2秒

#### 2.3.3 智能合约

**核心合约**：
- `EvidenceStorage`：审计证据存证存储
- `EvidenceVerification`：证据验证逻辑
- `AccessControl`：访问控制权限
- `AuditTrail`：存证操作审计
