### 2.2 模块详细设计

#### 2.2.1 LLM语义分析引擎

LLM语义分析引擎是方案的核心，利用大语言模型的深度语义理解能力检测文本中的舞弊信号。

**技术选型**：
- 基础模型：GPT-4/Claude-3（云端API）或 私有化部署（如ChatGLM-130B/Qwen-72B）
- 微调策略：基于舞弊审计文本数据集的指令微调

**分析能力**：

| 分析维度 | 检测内容 | 方法 |
|---------|---------|------|
| 隐含意图识别 | 文本中隐藏的真实意图（如施压、威胁、暗示） | LLM Prompt分析 |
| 语义矛盾检测 | 同一人或同一事件不同描述间的矛盾 | 跨文档语义比对 |
| 异常语义检测 | 与正常沟通模式偏离的异常语义 | 异常度评分 |
| 敏感话题识别 | 涉及舞弊相关话题的文本 | 主题分类 |
| 信息隐藏检测 | 刻意回避、模糊表达、信息缺失 | 信息完整性分析 |

**典型Prompt设计**：
```
分析以下文本是否存在舞弊相关信号。请从以下维度评估：
1. 是否存在异常压力或胁迫的迹象
2. 是否存在隐瞒或回避关键信息
3. 是否存在与正常业务不符的异常表达
4. 是否存在敏感或违规内容的暗示

文本内容：
{text}

请按JSON格式输出：
{
  "fraud_signals": [...],
  "risk_score": 0-100,
  "analysis": "...",
  "recommended_action": "..."
}
```

#### 2.2.2 情感分析引擎

情感分析引擎检测文本中的情感特征和情感不一致信号。

**分析维度**：

| 维度 | 说明 | 舞弊信号 |
|------|------|---------|
| 情感极性 | 正面/负面/中性 | 异常负面（防御性）或异常正面（讨好） |
| 情感强度 | 情感表达的强烈程度 | 过度强烈或过度平淡 |
| 情感波动 | 同一人在不同时间的情感变化 | 异常波动可能暗示压力 |
| 情感不一致 | 文本内容与情感的不匹配 | 正面描述负面事件等 |
| 情绪状态 | 愤怒/焦虑/紧张/回避等 | 特定情绪与舞弊相关 |

**技术实现**：
- 基于BERT微调的情感分类模型
- 时序情感分析（追踪同一人在时间轴上的情感变化）
- 跨文本情感对比（同一事件不同描述者的情感差异）

#### 2.2.3 异常关键词引擎

**关键词库构建**：
- **静态关键词库**：已知舞弊相关词汇（如回扣、好处费、特殊处理等）
- **动态关键词库**：基于Word2Vec/GloVe的词向量相似度扩展
- **领域关键词**：针对不同业务领域的特定关键词（如采购领域的"围标"、"陪标"）

**异常关键词检测**：
- 关键词频率异常（某段时间内特定关键词出现频率激增）
- 关键词共现异常（正常情况下很少同时出现的关键词共同出现）
- 关键词语境异常（关键词出现在不寻常的语境中）

#### 2.2.4 主题建模引擎

**技术选型**：
- LDA（Latent Dirichlet Allocation）：传统主题建模
- BERTopic：基于BERT嵌入的主题建模（更精确）

**应用场景**：
- 发现异常主题（与正常业务无关的隐藏主题）
- 主题演化分析（主题内容随时间的变化）
- 主题异常检测（偏离正常业务主题的异常文本）

#### 2.2.5 合同风险分析

**检测内容**：
- 异常付款条款（预付款比例过高、付款条件异常宽松）
- 异常免责条款（过度免责、责任上限异常低）
- 异常变更条款（变更流程过于简单、变更权限过大）
- 关联方条款（与关联方的特殊安排）
- 模糊条款（关键定义模糊、履约标准不清晰）

**技术实现**：
- 基于LLM的条款风险分类
- 合同条款模板比对（偏离标准模板的条款标记为异常）
- 合同条款关联分析（多份合同之间的条款关联性分析）
