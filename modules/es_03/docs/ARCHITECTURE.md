### 2.2 卫星数据源

#### 2.2.1 卫星数据源对比

| 卫星/传感器 | 空间分辨率 | 时间分辨率 | 光谱波段 | 数据获取 | 覆盖范围 |
|-------------|-----------|-----------|----------|----------|----------|
| Sentinel-2 | 10-60m | 5天 | 13个波段 | 免费开放 | 全球 |
| PlanetScope | 3-5m | 每日 | 4-8个波段 | 商业付费 | 全球 |
| Landsat 8/9 | 15-30m | 16天 | 11个波段 | 免费开放 | 全球 |
| MODIS | 250-1000m | 每日 | 36个波段 | 免费开放 | 全球 |
| GF系列（高分） | 0.5-4m | 按需 | 多光谱 | 商业付费 | 中国及全球 |

#### 2.2.2 数据获取策略

- **常规监测**：Sentinel-2（免费，5天重访）作为主力数据源
- **精细分析**：PlanetScope（3-5m分辨率，每日）用于重点区域精细分析
- **历史回溯**：Landsat数据（40年历史存档）用于历史变化追溯
- **热异常监测**：MODIS数据用于火灾、热异常等快速监测
- **按需采购**：针对特定事件的高分卫星数据按需采购

### 2.3 遥感图像预处理

#### 2.3.1 预处理流水线

```
原始影像 → 辐射定标 → 大气校正（6S/Sen2Cor） → 几何校正 → 云检测/掩膜 → 影像融合 → 预处理完成
```

- **大气校正**：采用Sen2Cor或6S模型，消除大气散射和吸收影响
- **云检测**：基于Fmask算法+深度学习云检测模型（Cloud-Net+）
- **影像融合**：全色波段与多光谱波段融合，提升空间分辨率
- **影像裁剪**：根据企业业务地点坐标自动裁剪ROI区域
- **时序堆叠**：将多期影像堆叠为时序数据，支持时序分析

#### 2.3.2 植被指数计算

| 指数名称 | 计算公式 | 用途 |
|----------|----------|------|
| NDVI（归一化植被指数） | (NIR-Red)/(NIR+Red) | 植被覆盖度、健康度 |
| EVI（增强型植被指数） | 2.5×(NIR-Red)/(NIR+6×Red-7.5×Blue+1) | 高植被区精细分析 |
| NDWI（归一化水体指数） | (Green-NIR)/(Green+NIR) | 水体提取 |
| NBR（归一化燃烧指数） | (NIR-SWIR2)/(NIR+SWIR2) | 火灾迹地检测 |
| LST（地表温度） | 热红外波段反演 | 热异常监测 |

### 2.4 CV分析模型

#### 2.4.1 土地利用分类模型

基于深度学习语义分割模型的土地利用分类：

| 类别 | 说明 | 训练数据来源 |
|------|------|-------------|
| 森林 | 林地、灌木林 | OpenEarthMap、自标注 |
| 农田 | 耕地、种植园 | OpenEarthMap、自标注 |
| 水体 | 河流、湖泊、水库 | OpenEarthMap、自标注 |
| 建设用地 | 工厂、建筑、道路 | OpenEarthMap、自标注 |
| 裸地 | 未利用地 | OpenEarthMap、自标注 |
| 湿地 | 沼泽、滩涂 | OpenEarthMap、自标注 |
| 矿山 | 采矿场、尾矿库 | 自标注 |
| 温室 | 农业大棚 | 自标注 |

**模型架构**：U-Net++/DeepLabV3+，骨干网络ResNet-101/EfficientNet-B4

#### 2.4.2 变化检测模型

基于孪生网络（Siamese Network）的变化检测：

- **双时相变化检测**：对比两期影像，识别新增/消失/变化区域
- **时序变化检测**：基于多期影像的时序变化趋势分析
- **异常变化检测**：识别偏离正常变化模式的变化

| 变化类型 | 检测内容 | 环境审计意义 |
|----------|----------|-------------|
| 森林砍伐 | 林地面积减少 | 企业是否承诺零毁林 |
| 水体污染 | 水体颜色/透明度变化 | 是否违规排放 |
| 施工活动 | 新建建筑/设施 | 是否超出环评范围 |
| 植被退化 | NDVI持续下降 | 生态恢复是否达标 |
| 矿山扩张 | 采矿区面积增加 | 是否超出采矿许可 |

#### 2.4.3 排放监测

- **热异常检测**：基于热红外波段识别工厂烟囱、火炬等热源
- **气溶胶监测**：基于MODIS气溶胶光学厚度（AOD）数据
- **甲烷排放监测**：基于Sentinel-5P的甲烷柱浓度数据
- **粉尘监测**：基于高分影像的粉尘扩散分析

### 2.5 绿色漂洗检测

#### 2.5.1 交叉验证体系

```
企业ESG声明 → 卫星遥感验证 → 传感器数据验证 → 第三方数据验证 → 偏差分析
```

| 企业常见声明 | 卫星验证方法 | 数据源 |
|-------------|-------------|--------|
| "森林零砍伐" | 林地变化检测 | Sentinel-2/PlanetScope |
| "生态恢复面积X公顷" | 植被覆盖度变化 | Sentinel-2时序数据 |
| "废水达标排放" | 水体污染监测 | Sentinel-2/Landsat |
| "减排XX%" | 热异常/气溶胶监测 | MODIS/Sentinel-5P |
| "绿色矿山" | 矿区植被恢复监测 | 高分卫星数据 |
| "零毁林供应链" | 供应商所在地森林监测 | Sentinel-2 |

#### 2.5.2 偏差评分

基于多维度交叉验证的绿色漂洗风险评分：

| 评分维度 | 权重 | 评分依据 |
|----------|------|----------|
| 声明与遥感数据一致性 | 35% | 卫星观测vs企业声明的一致性程度 |
| 历史变化趋势 | 20% | 环境指标的历史变化是否与企业声明一致 |
| 同行业对标 | 15% | 与同行业企业的环境表现对比 |
| 第三方数据印证 | 15% | 与政府监测、NGO报告等第三方数据的一致性 |
| 透明度评分 | 15% | 企业ESG披露的详细程度和数据可验证性 |
