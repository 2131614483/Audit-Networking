### 2.2 LLM分析生成模块

#### 2.2.1 审计说明生成模板

```
LLM生成审计说明 — 示例（应收账款底稿）

输入数据：
  • 科目：应收账款
  • 本年余额：¥123,456,789
  • 上年余额：¥107,354,599
  • 增长率：15%
  • 坏账准备：¥6,172,839（计提比例5%）
  • 账龄结构：1年内60%、1-2年25%、2-3年10%、3年以上5%
  • 周转天数：65天（上年：58天）
  • 行业平均周转天数：55天

LLM生成的审计说明（初稿）：

"1. 余额分析
   应收账款年末余额¥1.23亿元，较上年增长15%，高于营业收入增长率10%，
   主要系第4季度销售占比提升（35%，上年28%）及回款周期延长所致。
   周转天数65天，较上年增加7天，高于行业平均水平55天，需关注回款风险。

2. 账龄分析
   账龄结构总体合理，1年内占比60%（上年65%），3年以上占比5%（上年4%），
   长账龄占比略有上升。已按会计政策计提坏账准备¥617万，计提比例5%，
   与上年一致，计提充分性需结合客户信用状况评估。

3. 异常交易
   ML异常检测标记出以下异常交易：
   (1) 客户A期末集中回款¥1,200万（12月30日到账），占比10%，
       结合销售合同和物流记录，已确认回款真实性。
   (2) 客户B账龄2-3年余额¥800万，本年无交易发生，
       已发函确认债务存在，建议评估是否需单项计提坏账。

4. 结论
   应收账款总体可确认，账龄和坏账准备计提合理，
   建议关注客户B长账龄款项的回收风险。"

审计师审核要点：
  ✓ 数据准确性（AI已从数据湖自动获取，准确）
  ✓ 分析逻辑合理性（AI逻辑清晰，需确认）
  ✗ 补充客户B的信用评估报告（需人工补充）
  ✓ 确认后定稿
```
