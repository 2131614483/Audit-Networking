### 2.3 ML问题检测

#### 2.3.1 检测模型体系

| 模型 | 算法 | 检测目标 | 输入特征 |
|------|------|----------|----------|
| 收入异常检测 | XGBoost | 收入确认异常 | 收入增长率、毛利率、应收账款周转率、现金流匹配度 |
| 成本异常检测 | 孤立森林 | 成本归集异常 | 成本结构、毛利率波动、期间费用率 |
| 资产减值检测 | LightGBM | 资产减值不足 | 资产周转率、账龄结构、行业对比 |
| 关联交易检测 | GNN | 关联交易异常 | 交易金额、定价偏离度、交易频率 |
| 内控缺陷检测 | 规则+ML | 内控缺陷识别 | 控制点测试结果、异常交易模式 |

#### 2.3.2 异常评分

```
异常评分 = ML模型得分 × 权重1 + 规则引擎得分 × 权重2 + 行业偏离度 × 权重3
```

| 评分区间 | 风险等级 | 含义 |
|----------|----------|------|
| ≥85分 | 高风险 | 很可能存在财务规范性问题 |
| 70-84分 | 中风险 | 可能存在财务规范性问题 |
| 50-69分 | 低风险 | 需要关注，但不一定有问题 |
| <50分 | 正常 | 未检测到明显异常 |

### 2.5 行业对标

#### 2.5.1 对标维度

| 对标维度 | 对标指标 | 数据来源 |
|----------|----------|----------|
| 盈利能力 | 毛利率、净利率、ROE | 同行业上市公司 |
| 资产质量 | 应收账款周转率、存货周转率 | 同行业上市公司 |
| 偿债能力 | 资产负债率、流动比率 | 同行业上市公司 |
| 现金流 | 经营现金流/净利润 | 同行业上市公司 |
| 税务特征 | 综合税负率 | 同行业上市公司 |
| 财务指标 | 各项财务比率 | 同行业上市公司 |

#### 2.5.2 偏离分析

```
偏离度 = (企业指标 - 行业中位数) / 行业中位数 × 100%

异常偏离 = |偏离度| > 阈值(行业标准差 × 2)
```

- **正向偏离**：指标优于行业，关注合理性
- **负向偏离**：指标劣于行业，关注风险点
- **趋势偏离**：指标变化趋势与行业相反，重点关注
