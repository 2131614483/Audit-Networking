### 2.2 模块详细设计

#### 2.2.1 用途分类引擎

**ML用途分类模型**：
- 基于采购发票的商品名称、用途说明、部门信息等特征
- 使用BERT微调模型进行多标签分类
- 分类类别：应税项目、免税项目、简易计税、集体福利、个人消费、非正常损失等

**比例划分**：
- 兼营免税项目时，按销售额比例划分进项税额
- 共同费用按合理标准分摊（面积/人数/收入等）
- 无法划分时按公式计算

#### 2.2.2 转出规则引擎

**核心转出场景**：

| 场景 | 规则 | 计算方法 |
|------|------|---------|
| 用途改变（免税→应税） | 已抵扣进项需转出 | 净值×税率 |
| 非正常损失 | 已抵扣进项需转出 | 原抵扣额 |
| 集体福利/个人消费 | 进项不得抵扣 | 全额转出 |
| 简易计税项目 | 进项不得抵扣 | 全额转出 |
| 兼营免税项目 | 按比例转出 | 进项税额×免税收入/总收入 |
| 进项税额无法划分 | 按公式计算转出 | 按销售额比例 |

**规则管理**：
- 规则版本管理（政策更新时更新规则）
- 规则优先级（特殊规则优先于通用规则）
- 规则测试（新规则上线前测试验证）

#### 2.2.3 LLM政策解读引擎

**功能**：
- 税务政策文档的智能检索和解读
- 复杂规则的自然语言解释
- 计算过程的步骤化说明
- 政策变更的影响分析

**使用场景**：
- 审计人员询问特定场景的转出规则
- 自动生成计算过程的政策依据说明
- 政策更新后的影响评估

#### 2.2.4 计算追溯引擎

**记录内容**：
- 计算依据：涉及的发票、业务单据、政策文件
- 计算过程：每一步的计算公式、参数、中间结果
- 计算结果：最终转出金额及明细
- 审核记录：审核人、审核时间、审核意见

**追溯能力**：
- 按发票追溯：某张发票的转出计算过程
- 按期间追溯：某月/某季度的转出汇总及明细
- 按场景追溯：某类转出场景的全部计算记录
