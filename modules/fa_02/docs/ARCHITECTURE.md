### 2.2 BERT字段名理解模型

#### 2.2.1 模型设计

```
BERT字段名理解模型 — 详细设计

模型选择：BERT-base-Chinese（中文预训练）
输入格式：
  [CLS] + 源字段名 + [SEP]
  示例：[CLS] 总账科目 [SEP]
  示例：[CLS] GL_ACCT [SEP]
  示例：[CLS] General Ledger Account [SEP]

嵌入向量：768维（BERT最后一层[CLS]向量）

训练数据：
  - 初始训练集：5,000+条人工标注的字段名-标准字段映射对
  - 涵盖：中文名/英文名/拼音缩写/混合命名/数字编码
  - 覆盖：100+类标准字段（科目/金额/日期/摘要/凭证号等）
  - 数据增强：随机大小写/缩写扩展/拼写变体

微调策略：
  - 冻结前10层BERT参数，微调后2层+分类头
  - 学习率：2e-5
  - Batch size：32
  - Epoch：5（早停法，patience=2）
  - 优化器：AdamW

评估指标：
  - Top-1准确率：>92%
  - Top-3准确率：>98%
  - 映射置信度校准：ECE < 0.05
```

### 2.3 XGBoost字段映射分类器

#### 2.3.1 特征工程

```
XGBoost映射分类器 — 特征设计

特征维度：共45维

文本特征（来自BERT嵌入，32维）：
  - BERT[CLS]向量（16维，PCA降维后）
  - 字段名长度、单词数、字符类型比例
  - 是否包含数字、特殊字符、下划线
  - 命名风格：驼峰/下划线/全大写/全小写/混合

统计特征（8维）：
  - 数据类型（数值/字符串/日期/布尔）
  - 唯一值比率、空值比率
  - 数值范围（min/max/mean/std）
  - 字符串平均长度

上下文特征（5维）：
  - 所在表的其他字段名（关联信息）
  - 表名语义（如含"voucher"表示凭证相关）
  - 数据源类型（ERP/银行/税务/工商）

模型参数：
  - n_estimators: 500
  - max_depth: 8
  - learning_rate: 0.05
  - subsample: 0.8
  - colsample_bytree: 0.7
  - objective: multi:softprob
  - eval_metric: mlogloss
```
