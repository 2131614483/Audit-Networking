### 2.2 历史沿革知识图谱

#### 2.2.1 实体类型

| 实体类型 | 核心属性 | 数据来源 |
|----------|----------|----------|
| 企业（Company） | 名称、统一信用代码、成立日期、注册资本 | 工商数据、档案 |
| 股东（Shareholder） | 名称、类型（个人/机构）、出资额、持股比例 | 工商档案、股东名册 |
| 股权变更事件（EquityChange） | 变更日期、变更类型、变更前后股权结构 | 股东会决议、转让协议 |
| 增资事件（CapitalIncrease） | 增资日期、增资方式、增资金额 | 增资协议、验资报告 |
| 改制事件（Restructuring） | 改制日期、改制方式、改制前后主体 | 改制文件 |
| 法律文件（Document） | 文件类型、签署日期、效力状态 | 企业档案 |

#### 2.2.2 关系类型

| 关系 | 起始→终止 | 说明 |
|------|-----------|------|
| 持有股权 | Shareholder → Company | 股东持有公司股权 |
| 发生变更 | Company → EquityChange | 公司发生股权变更 |
| 参与增资 | Shareholder → CapitalIncrease | 股东参与增资 |
| 导致变更 | Document → EquityChange | 法律文件导致股权变更 |
| 前后承接 | EquityChange → EquityChange | 股权变更的先后顺序 |
| 关联企业 | Company → Company | 企业间的关联关系 |

### 2.4 时间线生成

#### 2.4.1 事件排序与时间线

```
股权变更事件 → 时间排序 → 冲突检测 → 时间线生成 → 可视化
```

**时间线生成规则：**

- **时间排序**：所有事件按时间顺序自动排列
- **时间冲突检测**：检测时间重叠、顺序矛盾等异常
- **关键节点标注**：标注重大变更节点（控制权变更、改制等）
- **时间区间划分**：按重要事件划分为多个阶段
- **并行事件处理**：同时发生的事件并行展示

#### 2.4.2 时间线视图

```

  │         │         │         │         │         │
  │──成立──→│──增资──→│──转让──→│──增资──→│──改制──→│
  │         │         │         │         │         │
张三:100%   张三:70%  李四:60%  李四:40%  XX股份

                              张三:30%
```

### 2.5 合规性检查

#### 2.5.1 检查规则库

| 检查维度 | 检查内容 | 法规依据 |
|----------|----------|----------|
| 出资合规 | 出资方式、出资期限、出资比例 | 公司法、注册资本登记管理规定 |
| 股权转让合规 | 转让程序、优先购买权、转让价格 | 公司法、公司章程 |
| 增资合规 | 增资决议程序、增资价格公允性 | 公司法、证券法 |
| 减资合规 | 减资决议、债权人通知、公告 | 公司法 |
| 改制合规 | 改制程序、资产评估、债权债务承继 | 公司法、企业改制规定 |
| 外资合规 | 外资准入限制、外汇登记 | 外商投资法 |
| 国有股权合规 | 国资审批、评估备案、进场交易 | 企业国有资产法 |

#### 2.5.2 异常检测

- **时间异常**：事件时间顺序矛盾、间隔异常
- **比例异常**：股权比例合计不等于100%、比例计算错误
- **程序异常**：缺少必要的决议文件、审批文件
- **价格异常**：转让价格明显不合理（与净资产差距过大）
- **主体异常**：股东资格不符合法律法规要求
