### 2.5 质量检查

#### 2.5.1 检查维度

| 检查维度 | 检查内容 | 评价标准 |
|----------|----------|----------|
| 完整性 | 是否覆盖所有风险点 | 风险覆盖矩阵 |
| 一致性 | 方法是否与目标一致 | 目标-方法映射 |
| 可行性 | 是否具备实施条件 | 资源-需求匹配 |
| 有效性 | 预期效果是否明确 | 效果评估模型 |
| 合规性 | 是否符合监管要求 | 法规比对检查 |

#### 2.5.2 质量评分

```
质量评分 = 完整性×25% + 一致性×20% + 可行性×20% + 有效性×20% + 合规性×15%
```

| 评分区间 | 等级 | 含义 |
|----------|------|------|
| ≥85分 | 优秀 | 方法论完善，可直接实施 |
| 70-84分 | 良好 | 方法论可行，需微调 |
| 60-69分 | 合格 | 方法论基本可行，需完善 |
| <60分 | 需改进 | 方法论需要重大调整 |
