### 2.2 模块详细设计

#### 2.2.1 知识图谱构建

**实体类型**：

| 实体 | 属性 | 来源 |
|------|------|------|
| 企业/公司 | 名称、注册号、法人、注册资本、行业、地址 | 工商数据、ERP |
| 个人 | 姓名、身份证号、电话、邮箱、职位 | HR系统、工商数据 |
| 账户 | 账号、银行、开户名、类型 | 财务系统 |
| 交易 | 金额、时间、类型、摘要 | ERP、银行 |
| 合同 | 编号、金额、日期、标的 | 合同系统 |
| 发票 | 号码、金额、开票方、受票方 | 税务系统 |

**关系类型**：

| 关系 | 说明 | 来源 |
|------|------|------|
| 交易关系 | A向B支付/转账 | 交易数据 |
| 股权关系 | A持有B股份 | 工商数据 |
| 任职关系 | A在B担任职务 | 工商/HR |
| 亲属关系 | A与B为亲属 | 申报/外部数据 |
| 联系方式共享 | 共享电话/地址/IP | 数据分析发现 |
| 合同关系 | A与B签署合同 | 合同系统 |
| 担保关系 | A为B提供担保 | 担保数据 |

#### 2.2.2 异常子图检测引擎

基于GNN的异常子图检测，自动识别图谱中的异常子结构。

**技术路线**：
- **GCN（图卷积网络）**：对节点和边进行特征学习
- **GAT（图注意力网络）**：学习不同邻居节点的重要性权重
- **GraphSAGE**：归纳式学习，支持新节点加入

**异常检测方法**：
1. **节点级异常**：检测异常节点（如异常活跃的供应商）
2. **边级异常**：检测异常交易关系（如异常资金流动）
3. **子图级异常**：检测异常子图结构（如环回交易群）

**模型训练**：
- 训练数据：标注的正常子图 + 人工标注的异常子图
- 损失函数：对比学习（正常vs异常子图）
- 评估指标：AUC-ROC、Precision@K

#### 2.2.3 隐藏关联发现引擎

**链路预测**：
- 基于Node2Vec/GraphSAGE图嵌入
- 预测两个实体之间是否存在隐藏的关联关系
- 关联类型预测（股权/亲属/利益关系）

**路径分析**：
- 最短路径分析（检测两个看似无关实体之间的连接路径）
- 多重路径分析（检测多个路径的连接模式）
- K步可达分析（检测间接关联）

**关联发现场景**：
- 供应商与审批人的隐藏关联
- 投标企业之间的隐藏关联（围标/串标）
- 客户与内部人员的利益关系
- 通过多层持股的最终实控人识别

#### 2.2.4 腐败模式匹配引擎

**预设模式库**：

| 模式名称 | 图模式 | 描述 |
|---------|--------|------|
| 回扣模式 | 供应商→(回扣)→员工，员工→(批准高价)→供应商 | 员工收受回扣批准高价采购 |
| 围标模式 | 多个供应商→(相同联系人/地址)→围标集团 | 多家投标企业实际控制人为同一人 |
| 利益输送 | A→(低价出售)→B，B→(高价回购)→A | 通过关联交易转移利益 |
| 资金空转 | A→B→C→A 循环资金流 | 虚假交易制造流水 |
| 影子公司 | 员工→(亲属/代持)→供应商，供应商→(交易)→公司 | 员工通过影子公司与公司交易 |

**模式匹配技术**：
- **子图同构匹配**：VF2算法精确匹配已知腐败模式
- **近似子图匹配**：容忍一定差异的模糊匹配
- **时序模式匹配**：考虑交易时间顺序的模式匹配

#### 2.2.5 环路检测引擎

**检测算法**：
- DFS（深度优先搜索）环检测
- Johnson算法（有向图找环）
- 强连通分量（SCC）分解

**应用场景**：
- 循环交易检测（资金空转、虚假交易）
- 循环担保检测（互相担保、担保链）
- 循环持股检测（交叉持股、循环持股）

#### 2.2.6 网络可视化与探索

**可视化技术**：
- 力导向布局（D3.js/G6/Vis.js）
- 分层布局（针对层级关系）
- 时序布局（展示关系随时间演变）
- 社区着色（不同社区不同颜色）

**交互探索**：
- 节点展开/折叠
- 路径高亮
- 属性筛选
- 子图导出
- 时序播放

### 2.3 图算法选型汇总

| 算法 | 用途 | 复杂度 | 工具 |
|------|------|--------|------|
| Louvain | 社区发现 | O(n log n) | Neo4j GDS |
| PageRank | 节点重要性 | O(n + m) | Neo4j GDS |
| Betweenness Centrality | 中介中心性 | O(nm) | Neo4j GDS |
| Node2Vec | 图嵌入 | O(n) | 自定义实现 |
| GCN/GAT | 节点分类/异常检测 | O(n) | PyTorch Geometric |
| VF2 | 子图同构 | O(n!)* | NetworkX |
| Johnson | 环检测 | O((n+e)(c+1)) | 自定义实现 |

*VF2最坏指数级，实际表现良好
