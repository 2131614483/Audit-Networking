### 2.2 模型回测

#### 2.2.1 回测方法

| 回测方法 | 说明 | 适用场景 |
|----------|------|----------|
| 时间序列回测 | 按时间顺序划分训练/测试集 | 标准回测方法 |
| 滚动窗口回测 | 固定窗口滚动预测 | 评估模型稳定性 |
| 交叉验证回测 | K折交叉验证 | 样本量较小时 |
| 外样本回测 | 独立样本验证 | 最终验证 |

#### 2.2.2 评估指标

| 指标类别 | 指标 | 计算公式 | 监管要求 |
|----------|------|----------|----------|
| 区分能力 | AUC | ROC曲线下面积 | ≥0.75 |
| 区分能力 | KS统计量 | 好坏客户累计分布最大差 | ≥0.3 |
| 区分能力 | 基尼系数 | 2×AUC-1 | ≥0.5 |

### 2.3 可解释性分析

#### 2.3.1 XAI方法

| XAI方法 | 原理 | 输出 |
|----------|------|------|
| SHAP | Shapley值 | 特征重要性排序、单个预测解释 |
| LIME | 局部可解释模型 | 单个预测的局部解释 |
| 特征重要性 | 模型内置重要性 | 全局特征排序 |
| 部分依赖图 | 特征对预测的边际效应 | 特征影响曲线 |
| 累计局部效应 | 无相关假设的特征效应 | 无偏特征效应 |

#### 2.3.2 验证报告中的可解释性

```
模型验证报告 - 可解释性部分

1. 全局解释
   - 前10重要特征及其贡献度
   - 特征与违约概率的关系曲线
   
2. 局部解释（示例客户）
   - 客户A违约预测：概率78%
   - 主要驱动因素：
     * 资产负债率(65%)：高于行业均值，增加违约风险
     * 现金流覆盖率(20%)：低于阈值，增加违约风险
     * 行业景气度(-15%)：行业向好，降低违约风险
     
3. 模型行为分析
   - 特征交互效应
   - 非线性关系检测
   - 异常预测模式
```

### 2.4 压力测试

#### 2.4.1 测试场景

| 场景 | 参数变化 | 预期影响 |
|------|----------|----------|
| 基准场景 | 当前经济条件 | 模型正常表现 |
| 轻度压力 | GDP增速-1%，利率+100bp | 违约率上升 |
| 中度压力 | GDP增速-2%，利率+200bp | 违约率明显上升 |
| 重度压力 | GDP增速-3%，利率+300bp | 违约率大幅上升 |
| 极端场景 | 金融危机参数 | 模型极限表现 |

#### 2.4.2 压力测试方法

- **情景分析**：设定宏观经济变量变化，评估对违约率的影响
- **敏感性分析**：单一变量变化对模型输出的影响
- **反向压力测试**：设定违约率目标，反推需要的压力条件
- **模型极限测试**：极端输入条件下的模型表现
