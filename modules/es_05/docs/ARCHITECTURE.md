### 2.3 RAG检索增强生成

#### 2.3.1 检索架构

```
用户查询 → 查询理解 → 多路检索 → 重排序 → LLM生成 → 回答
```

**多路检索策略：**

| 检索路径 | 技术方案 | 用途 |
|----------|----------|------|
| 向量检索 | text-embedding-3 + FAISS | 语义相似度检索 |
| 关键词检索 | Elasticsearch BM25 | 精确匹配检索 |
| 图谱检索 | Cypher查询 | 结构化知识检索 |
| 混合检索 | RRF融合策略 | 综合排序 |

#### 2.3.2 检索优化

- **查询改写**：基于LLM的查询扩展和改写，提升检索命中率
- **分块策略**：自适应分块（按章节、按段落、按句子），块大小512 tokens
- **元数据过滤**：按标准、行业、地区等元数据字段过滤
- **上下文增强**：检索结果包含前后文，提供完整上下文
- **相关性反馈**：基于用户反馈的在线学习，持续优化排序

### 2.4 LLM问答引擎

#### 2.4.1 问答能力

| 能力类型 | 示例问题 | 技术方案 |
|----------|----------|----------|
| 标准解读 | "ISSB IFRS S2中Scope1排放披露要求是什么？" | RAG+LLM |
| 标准比对 | "GRI 305和SASB气候指标有什么差异？" | KG推理+RAG |
| 合规检查 | "我们的ESG报告是否符合CSRD要求？" | 标准比对+检查清单 |
| 方法论推荐 | "化工行业ESG审计应该采用什么方法？" | 知识图谱+案例检索 |
| 术语解释 | "什么是双重重要性评估？" | 知识库检索 |
| 实操指导 | "如何计算Scope3的采购商品和服务类别？" | 方法论库+步骤生成 |

#### 2.4.2 回答质量保障

- **引用标注**：所有回答标注信息来源（标准名称、章节、页码）
- **置信度评分**：基于检索匹配度和LLM置信度的回答可信度评分
- **免责声明**：标注AI辅助性质，重要决策需人工确认
- **多轮对话**：支持追问、澄清、深入探讨的上下文对话
- **反馈机制**：用户对回答质量进行反馈，持续优化

### 2.5 智能功能模块

#### 2.5.1 标准比对工具

- **一对一比对**：两个标准的逐项比对（如ISSB vs GRI）
- **一对多比对**：一个标准与多个标准的交叉比对
- **差异高亮**：自动标注不同标准之间的差异点
- **映射表生成**：自动生成标准间的指标映射关系表

#### 2.5.2 方法论推荐

- **场景识别**：基于审计任务描述自动识别适用场景
- **方法匹配**：从方法论知识库中匹配最适合的审计方法
- **步骤生成**：生成具体的审计步骤和检查清单
- **模板推荐**：推荐适用的工作底稿模板

#### 2.5.3 学习助手

- **知识路径**：根据用户角色和学习目标推荐学习路径
- **知识测验**：自动生成ESG标准知识测验题目
- **学习进度**：追踪用户知识学习进度和薄弱环节
- **每日推送**：ESG标准更新和行业动态推送
