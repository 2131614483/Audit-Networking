⚠️ 请使用 launch.py 启动平台

检测到您是通过通用文件服务器直接打开的目录，这样 无法访问 API 接口（审计数据、AI 总结都会失败）。

✅ 正确启动方式

cd c:\Pythonproject\解决方案详细报告
.venv\Scripts\python.exe launch.py

如果浏览器支持自动跳转，正在尝试跳转到静态页面： web/index.html（仅预览 UI，数据接口不可用）

📌 启动参数

  • launch.py — 默认端口 8765，自动打开浏览器
  • launch.py --regen — 强制重新运行审计生成数据
  • launch.py --port 8888 — 指定端口
  • launch.py --no-browser — 不自动打开浏览器
